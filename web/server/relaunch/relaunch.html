Raffle draw

Paste the hash of the block you announced and draw. The draw is decided entirely by that hash and the ticket list below, it runs in this page, and anyone can repeat it. Nobody can win twice: a winner's tickets all leave the pool.

How the draw works, so you can check it yourself
  1. The entrants are the list below, in that exact order: most tickets first, and ties broken by the id column, which is the first 12 hex characters of sha256(wallet). The order never depends on the database.
  2. The seed is your text with spaces trimmed, a leading 0x removed and everything lowercased.
  3. For winner number i (starting at 0) the page hashes <seed>:<i> with SHA-256, reads the first 16 bytes as one big number and takes it modulo the tickets still in the pool. That is the winning ticket; whoever holds it wins.
  4. The winner and all of their tickets are removed, then the next number is drawn the same way.

Each winner below shows the exact text that was hashed, the 16 bytes that came out and the ticket it landed on, so the whole draw can be redone with any SHA-256 tool. On a Mac: printf '%s' '<seed>:0' | shasum -a 256
